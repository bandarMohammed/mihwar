## 2. جهّز جهازك (مرة وحدة)

1. ثبّت: **Git** · **Node.js** (نسخة LTS) · **Docker Desktop** · **VS Code** · **Claude Code**.
2. سو حساب **GitHub** (لو ما عندك)، وأرسل اسم المستخدم لقائدك.
3. اقبل دعوة المستودع من بريدك أو من GitHub.
4. نزّل المستودع: `git clone` ثم رابط المستودع، وافتح المجلد في Claude Code.
5. أول مرة: اطلب من Claude Code «شغّل المشروع عندي حسب قسم Commands في CLAUDE.md» (بعد ما تجهزه المجموعة 3 في T-080).

## 4. كل مهمة بهذا الترتيب

1. حدّث فرع مجموعتك `group-1-wasl` قبل ما تبدأ (`git pull`).
2. الصق البرومت في Claude Code برقم مهمتك.
3. راجع كل اللي كتبه Claude Code وافهمه — أنت المسؤول عنه.
4. ارفع فرعك وافتح **Pull Request على `group-1-wasl`** (مو `main`)، واكتب فيه كل معيار قبول وكيف تحققت منه.
5. زملاؤك يراجعون، والقائد يراجع ويدمج في فرع المجموعة، والمنسق أو لينا الطلحي يدمجونه في `main`. **لا تدمج بنفسك.** لو أحد طلب تعديل، عدّل على نفس فرعك.
6. وراجع أنت شغل زملائك: افتح الـ Pull Request، واكتب ملاحظاتك، واختر Approve أو Request changes، **بدون Merge**.

## 5. ممنوع

- رفع كلمات مرور أو مفاتيح أو ملف `.env`.
- تعديل ملفات `docs/` بدون موافقة المنسق.
- الدمج (Merge) لأي عضو غير القائد، أو تخلي الذكاء الاصطناعي يدمج بدالك.
- إضافة شي مو موجود في مهمتك، أو البناء على قرار مكتوب `proposed`.
- الرفع المباشر على `main` أو على `group-1-wasl`.

## 6. لو علقت
