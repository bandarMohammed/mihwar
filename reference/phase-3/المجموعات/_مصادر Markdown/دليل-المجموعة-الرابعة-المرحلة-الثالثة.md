## 1. مهمتنا باختصار

نبني الذكاء الاصطناعي الواحد لمحور: ذكاء وصل (التصنيف والأولوية والتوجيه)، والعقل التشغيلي (بيانات الشركة والتحليل والمؤشرات والرؤى والمشكلات)، وشاشات الإدارة العليا، و«اسأل محور» لكل الأدوار، والتوصيات والتقارير.

- **مهامنا:** 24 مهمة — Must 15 · Should 6 · Later 3.
- **القائد:** العضو 4 — يوزّع ويتابع ويراجع ويدمج، ويرسل للمنسق تقرير نهاية كل أسبوع.
- **المخرج النهائي:** كل مهام Must مدموجة في `main` ومعايير قبولها ناجحة، وتشتغل مع شغل المجموعات الثانية.
- **فرع مجموعتنا في GitHub:** `group-4-ai` — كل Pull Request يروح له مو لـ `main`. القائد يدمج فيه، والمنسق يدمجه في `main`.

## 5. قواعد مهمة لمجموعتنا

- ذكاء اصطناعي **واحد** لمحور (✅ Q-14)، واسم النموذج في الإعدادات مو في الكود.
- ما يوصل للنموذج إلا البيانات المسموحة لدور المستخدم، وبدون اسم الموظف أو رقمه، والإدارة العليا أرقام مجمّعة.
- كل نتيجة (رؤية، مشكلة، توصية، إجابة) فيها **مصدر البيانات وتاريخ التحليل** ومرتبطة بعملية التحليل (NFR-25 · NFR-27).
- قواعد الثقة: 0.85 تلقائي · 0.60 إلى 0.85 مع علامة مراجعة · أقل سؤال توضيحي واحد (ADR-4202).
- مهمة وحدة لكل فرع ولكل Pull Request، والـ Pull Request على `group-4-ai`. والأسماء من `docs/glossary.md`، والصلاحيات تنفحص في الخادم.
- **قرارات المنسق اللي تأثر علينا:** مزوّد الذكاء الاصطناعي (T-260 · T-460 · T-560)، ومكان شاشة استيراد بيانات الشركة (T-401).

## 7. قائمة تحقق القائد قبل دمج أي Pull Request

- [ ] الـ PR لمهمة وحدة، **وهدفه `group-4-ai`**، والفرع والـ commits برقمها (`T-xxx`).
- [ ] كل معيار قبول للمهمة مذكور في الوصف، ومعه اختبار ناجح.
- [ ] الفحص التلقائي (CI) أخضر.
- [ ] الصلاحيات تنفحص في الخادم (جرّب بحساب دور ثاني).
- [ ] الشاشة عربية RTL، فيها الحالات الخمس، وبألوان ومكوّنات `docs/design-system.md`.
- [ ] الأسماء من `docs/glossary.md`، وما فيه كلمات مرور أو مفاتيح مرفوعة.
- [ ] ما تغيّر شي في `docs/` بدون موافقة المنسق، وما انبنى شي على قرار `proposed`.
- [ ] نتائج الذكاء الاصطناعي فيها مصدر البيانات وتاريخ التحليل، وما وصل للنموذج إلا المسموح للدور.

**برومت القائد للمراجعة:**

> أنا قائد المجموعة 4 بمشروع محور. راجع الـ Pull Request رقم [..] للمهمة [T-xxx] حسب «قائمة تحقق القائد» في دليل مجموعتي و`docs/acceptance-criteria.md`، وأعطني تقرير: وش ناجح، ووش ناقص، ووش لازم يتعدل قبل الدمج.
