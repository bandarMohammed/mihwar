## 4. جلسة التحسين البصري مع المنسق (2026-11-23)
1. ✅ محادثة «اسأل محور»: سؤال المستخدم يمين وإجابة محور يسار.
2. ✅ الزر الأساسي بتدرّج الهوية ونص أبيض (Q-2012). باقٍ: ظل/توهج الزر (Q-2003) وفجوة البطاقات (Q-2002).
3. ✅ شعار محور الحقيقي في القائمة الجانبية (Q-2009).
4. ✅ SCR-080 بعرض 1440.
5. ✅ القائمة الجانبية القابلة للإخفاء، وزر الثيم، والوضعان الفاتح والداكن، ورسوم بيانية للإدارة العليا (SCR-040 · SCR-441 · SCR-442)، وجداول برأس فاتح وعمود «إجراء»، ونقش خلفية خفيف لكل الصفحات.
6. ✅ بطاقة المستخدم وزر «تسجيل الخروج» وشاشة «حسابي» SCR-081 (ADR-1003).
7. باقٍ (اختياري): عرض «اسأل محور» لبقية الأدوار، وإزالة المكتبات الجاهزة غير المستخدمة (Q-2007) بعد موافقة المنسق.
