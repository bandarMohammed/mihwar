## 5. الأيقونات (37 مكوّنًا `Icon/<name>`)
شبكة 24px، سمك الخط 1.75، أطراف ونهايات دائرية، خطّية (outline) فقط، اللون مربوط بـ `color/icon/default` (وللحالة النشطة `color/icon/active`).

home · chart · doc · user · users · sliders · bell · chat · brain · spark · db · trend · search · filter · calendar · plus · link · flow · alert · target · shield · clock · layers · arrow-next · وأيقونات إضافية: check · x-circle · refresh · send · inbox · chevron-down · lock · bolt · ⟵ 0.4: sun · moon · menu · sidebar · logout.

ملاحظة RTL: `arrow-next` يشير لليسار (التالي في الاتجاه العربي)، و`logout` سهمه يطلع لليسار من باب على اليمين.

## 6. قواعد الاستخدام و RTL
1. لا ألوان ولا أحجام خارج المتغيرات والأنماط أعلاه.
2. النص العربي محاذى لليمين؛ الصفوف الأفقية يكون أول عنصر فيها على اليمين.
3. الأرقام والنصوص اللاتينية بخط Inter وفي سطر مستقل إن بدأ الوصف بحروف لاتينية (تجنبًا لاضطراب ترتيب bidi).
4. الأيقونات لا تُلوَّن يدويًا؛ تُربط بالمتغير.
5. كل الشاشات تستخدم مكوّنات الصفحة 1 فقط.
6. ⟵ أسماء الحالات والأولويات والفئات في الشارات والجداول تُؤخذ من `docs/glossary.md` فقط (القسم 8.2)، وأرقام الطلبات بصيغة `REQ-YYYY-NNNNN` (وليست أرقام شاشات SCR).

## 8. المكوّنات (الصفحة 1)
كل المكوّنات مربوطة بمتغيرات الألوان والمسافات والزوايا وأنماط الخطوط أعلاه.

**العضو 2 — الأزرار والحقول والنماذج (قسم 02)**
- `Button`: variant = primary / secondary / ghost / danger / icon، size = sm 40 / md 48 / lg 56، state = default / hover / focus / pressed / disabled / loading. خصائص: Label، أيقونة بداية/نهاية، Icon asset.
- `Field`: type = text / search / select / textarea / attachment / password / checkbox، state = default / hover / focus / filled / error / success / disabled / read-only. خصائص: Label، Value، Helper، Required.
- نماذج مركّبة: `Form / Assignment`، `Form / Status Update`، `Form / Department Filters`.

**العضو 3 — البطاقات والجداول والشارات والتنقل (قسم 03)**
- `Badge`: Status = ok / warn / bad / info / ai / slate (ألوان tint المعتمدة، زاوية pill).
- `Card/KPI` (رقم Inter بنمط Numeric KPI) و`Card/General`، زاوية card وظل Shadow/Card.
- `Table/Header Row`، `Table/Row — Status`، `Table/Row — Data` (Zebra = false / true). الأعمدة بترتيب RTL: العمود الأول على اليمين. إطار الجدول: زاوية card + Shadow/Card + حد border/default.
- `Nav/Sidebar` (الإدارة العليا) و`Nav/Sidebar — Employee` و`Nav/Sidebar — Department Manager`: عرض 260، الجانب الأيمن، خلفية color/bg/dark. العنصر النشط بخلفية `color/bg/nav-active` وشريط cyan.

**العضو 4 — الحالات الخمس وتسجيل الدخول (قسم 04)**
- `State / Loading` · `Success` · `Error` · `Empty` · `No Access`، وشاشة SCR-080 تسجيل الدخول بالشعار الملوّن.

### 8.1 متغيرات أضافتها المجموعة بعد الإصدار الأول
- `color/bg/nav-active` (Color collection): خلفية عنصر التنقل النشط = brand/blue بنسبة 30% فوق brand/night. اشتُقّت لأن شفافية الطلاء المربوط بمتغير لم تُطبَّق في العرض.
