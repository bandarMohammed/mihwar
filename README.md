## وش المطلوب منك؟
1. **اقرأ خطة المرحلة الثالثة** `reference/phase-3/phase-3-plan.pdf`، ودليل مجموعتك في `reference/phase-3/المجموعات/`.
2. **اعرف مهامك** من دليل مجموعتك (القسم 2)، واقرأ كل مهمة ومعايير قبولها في `docs/tasks.md`.
3. **البرمجة في مستودع GitHub** (بتوصلك دعوة). هذا المجلد المضغوط نسخة للقراءة بس، لا تعدّل عليه.
4. **في Claude Code:** افتح مجلد المستودع، والصق البرومت الجاهز من دليل مجموعتك (القسم 6) برقم مهمتك.
5. **كل مهمة** في فرع وحده (`feature/T-230-...`) وPull Request وحده، وفيه كل معيار قبول وكيف تحققت منه. القائد يراجعه ويدمجه.

## مهم
- ابدأ بمهام **Must**. مهام **Should** بس بعد ما تخلص Must حقتك، ومهام **Later** ما تنبرمج في هذي المرحلة.
- لا تعدّل ملفات `docs/` بدون موافقة المنسق، ولا ترفع كلمات مرور أو مفاتيح (`.env`).
- لو لقيت تعارض بين ملفين، أو قرار مكتوب `proposed`، وقف واسأل قائدك.
